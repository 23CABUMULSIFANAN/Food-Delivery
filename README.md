# Food Delivery Application

A responsive food ordering web application developed using React.js. Users can browse food items, add products to cart, and manage orders dynamically.

## Features

- Dynamic Cart Functionality
- Real-Time Price Calculation
- Category-Based Food Filtering
- Responsive Design
- React Hooks State Management
- Reusable Components

## Tech Stack

- React.js
- JavaScript
- HTML
- CSS
- Bootstrap
